# National coffee statistics (work in progress)

Official national / FAO statistics collected to cross-check and complete the USDA-based
balance sheets (Ethiopia, Uganda, Mexico, Peru, Indonesia) of `Balance_Sheet_weather_MI.xlsx`.

- `tools/pdftext.py`  – stdlib-only PDF text extractor (`python3 tools/pdftext.py file.pdf`, or `from pdftext import lines`)
- `tools/pdfimages.py` – stdlib-only extraction of images embedded in a PDF

Data files and source notes are added below this folder by the collection session.
